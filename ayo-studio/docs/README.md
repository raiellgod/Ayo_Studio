## Regra de manutenção

Ao terminar uma feature ou tomar uma decisão relevante:

1. atualizar `05_DEV_STATE.md`;
2. marcar o progresso em `09_ROADMAP.md`;
3. atualizar o documento específico afetado;
4. adicionar novas regras em `08_BUSINESS_RULES.md`;
5. criar/atualizar cápsulas em `06_FEATURE_CAPSULES.md`.

A documentação deve acompanhar o código.
